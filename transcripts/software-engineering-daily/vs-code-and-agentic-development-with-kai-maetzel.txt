[0:00:00] ANNOUNCER: Visual Studio Code has become one of the most influential tools in modern software development. The open-source code editor has evolved into a platform used by millions of developers around the world. And it has reshaped expectations for what a modern development environment can be through its intuitive UX, rich extension marketplace, and deep integration with today's tooling landscape. Now, in an era defined by rapid advances in AI-assisted programming, VS Code is at the center of a profound shift in how software is written.

Kevin Ball, or KBall, is the Vice President of Engineering at Mento and an independent coach for engineers and engineering leaders.
